# repo-pz4
## Создание приватного репозитория и совместная работа

**Цель:** освоить приёмы создания приватного (сетевого) репозитория на GitHub, научиться наполнять его файлами различных форматов, выполнять ветвление, клонировать репозиторий для получения локальной версии, а также организовывать совместную работу с другими пользователями (коллабораторами).

**Автор:** Тимченко Л.А.

### Содержимое репозитория
- `info.txt` — текстовая информация
- `document.pdf` — PDF-документ
- `image.png` — изображение

### Ветки
- `main` — основная ветка
- `feature-docs` — текстовые документы
- `feature-images` — графические документы
- `feature-pdf` — PDF-документы
- `feature-extra` — дополнительные документы
